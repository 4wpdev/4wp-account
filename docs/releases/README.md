# Release notes (4WP Account)

Short drafts for **Google Business Profile**, social, newsletter, [4wp.dev](https://4wp.dev/).  
WordPress.org changelog stays in [readme.txt](../../readme.txt).

## Workflow

1. Ship version (Git + SVN when listed).
2. Add `{version}.md` here (agent writes the short note).
3. **Publish on Google Business Profile → Updates / News** (manual).
4. Later: sync these notes into the 4wp.dev plugin page body (via 4WP FAQ / related) — not automated yet.

Excluded via `.distignore`.
