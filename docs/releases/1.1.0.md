# 4WP Account 1.1.0

**Published:** 2026-09-08  
**WordPress.org:** https://wordpress.org/plugins/4wp-account/  
**GitHub:** https://github.com/4wpdev/4wp-account

## Summary

Membership user account hub for WordPress — registration, profile cabinet, and social login with Gutenberg blocks.

## Highlights

- Stable membership release: account page, registration, user profile cabinet
- Safer `wp-login.php` replacement (only when the page already has a login block/shortcode)
- OAuth auth URL / state no longer cached (REST + front-end)
- Tested up to WordPress 7.1
